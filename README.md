# 📌 Doctor Appointment Management System

A full-stack Doctor Appointment Management System built to simplify the process of booking and managing doctor appointments online. Users can register, update their profile, search doctors, and book appointments in a seamless and modern interface. The system is designed with a clean UI, fast performance, and scalable backend architecture.

This project demonstrates real-world full-stack development using Next.js, Express, and MongoDB with proper REST API integration.

🔗 Live Site: https://medislot-client.vercel.app

## 🛠️ Tech Stack

### Frontend
- Next.js 
- Tailwind CSS / HeroUI
- React Icons
- React Hot Toast
- Fetch API

### Backend
- Node.js
- Express.js
- MongoDB


---

## ✨ Features

- 👤 User authentication system (login & register support)
- 📝 Update user profile (name & profile image)
- 📅 Book doctor appointments with available time slots
- 🔍 Search doctors by name, category, or specialization
- 🧑‍⚕️ Doctor listing with detailed profile pages
- ⚡ Fast REST API integration with Express & MongoDB
- 🎨 Fully responsive UI (mobile, tablet, desktop)
- 🔄 Instant UI update after profile modification
- 🌙 Dark mode support (if enabled)
- Appointment cancellation & rescheduling
- Admin dashboard
